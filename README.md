# Aquecimento Solar da Piscina Escolar

Site do Projeto Integrador, que também funciona como apresentação.
**Equipe:** Amanda · Beatriz · Daniel · Rafaela

## O que tem aqui

```
index.html              ← O SITE INTEIRO (texto, visual e botões, tudo num arquivo só)
imagens/                ← coloque aqui imagem1.jpg ... imagem10.jpg
LISTA_DE_IMAGENS.txt    ← o que vai em cada imagem
```

## Testar no computador

1. **Descompacte o .zip primeiro** (botão direito → "Extrair tudo").
2. Entre na pasta extraída e dê dois cliques no `index.html`.

## Publicar no GitHub Pages

1. github.com → **+** → **New repository** → nome `piscina-solar`, **Public** → **Create repository**.
2. Clique em **uploading an existing file**.
3. Arraste **o `index.html` e a pasta `imagens`** (com as fotos dentro) → **Commit changes**.
4. **Settings → Pages → Branch: main, / (root) → Save**.
5. Espere 1 a 2 minutos: o link aparece ali (ex.: `https://SEU-USUARIO.github.io/piscina-solar/`).

Se a pasta `imagens` não subir junto, pode enviar as fotos soltas, ao lado do `index.html`. O site também as encontra lá.

**Trocar uma foto depois:** envie outra com o mesmo nome (ex.: `imagem3.jpg`). Nomes sempre em minúsculo e sem espaço.
